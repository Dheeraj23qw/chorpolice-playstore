# WALLET SLICE WORKFLOW

1. **State Structure:**

   * `coins`: Total coins in the wallet.
   * `transactions`: Array of all credit/debit transactions.
   * `initialized`: Boolean flag to track first-time initialization.
   * `totalBySource`: Object tracking total coins earned from each source (quiz, spin, daily bonus, etc.).

2. **Actions:**

   * `setWallet`: Replace the entire wallet state.
   * `markInitialized`: Set `initialized` flag to true.
   * `creditCoins`: Add coins with reason, source, metadata, timestamp. Updates `totalBySource`.
   * `debitCoins`: Subtract coins with reason, source, metadata, timestamp.
   * `resetWallet`: Reset coins, transactions, and totals to initial state.

3. **Transaction Object:**

   * `id`: Unique ID (timestamp-based).
   * `type`: "CREDIT" or "DEBIT".
   * `amount`: Coin amount.
   * `reason`: Human-readable description.
   * `source`: Where coins came from (quiz_reward, spin_reward, app_share, etc.).
   * `metadata`: Optional extra info (e.g., quiz level, segment label).
   * `timestamp`: Exact time of transaction.

4. **Selectors:**

   * `selectWalletState`: Full wallet state.
   * `selectCoins`: Current total coins.
   * `selectTransactions`: All transactions.
   * `selectRecentTransactions`: Last 5 transactions.
   * `selectTotalCredits` / `selectTotalDebits`: Sum of credit/debit transactions.
   * `selectTotalBySource`: Coins grouped by source.
   * `selectTransactionsBySource(source)`: Transactions filtered by source.
   * `selectRecentTransactionsBySource(source, limit)`: Last N transactions by source.
   * `selectCreditCount` / `selectDebitCount`: Count of credit/debit transactions.

5. **Use Cases:**

   * Track coin flow from different app features (quiz, spin, share, daily bonus).
   * Display wallet balance and transaction history.
   * Analytics on which source generates most coins.
   * Show recent transactions in UI.
   * Reset wallet or initialize on first app launch.

6. **Integration Tips:**

   * Always dispatch `creditCoins` or `debitCoins` for any coin change.
   * Use selectors to read wallet data in components.
   * Store metadata for analytics or reporting.
   * Use `initializeWallet` thunk for first-time setup.
